单证提取填充工具 v2.5 —— 离线自包含便携包
================================================

适用系统：Windows（x64）
特点：无需安装 Python、无需联网、不依赖公司内网，解压即用。

────────────────────────────────────────
【第一次使用】
────────────────────────────────────────
1. 把整个文件夹解压到目标电脑的任意位置
   （建议路径不含中文或空格，例如 D:\booking-fill-tool）。
2. 双击 start_server.bat 启动服务
   - 脚本会自动启动服务并弹出浏览器，访问固定地址 http://127.0.0.1:8002/
   - 服务窗口会最小化在任务栏，请勿关闭（关闭即停止服务）
3. 若浏览器未自动弹出，请手动访问固定地址 http://127.0.0.1:8002/ 即可使用。

功能说明：
• 客户SKU管理：新增 / 编辑 / 删除 SKU，编辑页为紧凑网格（6 列），
  产品图片支持「点击选择 / 拖拽 / Ctrl+V 粘贴截图」三种上传方式。
• 托书生成：完全离线，模板已随本包附带（见 assets\ 目录），
  不依赖原来的公司内网共享盘。

────────────────────────────────────────
【长期使用 / 开机自动启动】
────────────────────────────────────────
• 把 start_server.bat 复制（或创建快捷方式）到开机启动文件夹：
  C:\Users\你的用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
  这样每次登录 Windows 会自动拉起服务。
• 服务自带「崩溃自动重启 + 端口看门狗」，关闭那个黑色窗口才会停止。

────────────────────────────────────────
【修改访问地址 / 端口】
────────────────────────────────────────
访问地址与端口统一写死在 config.json（字段 host / port / access_url），
例如默认 "127.0.0.1" / 8002 / "http://127.0.0.1:8002/"。
start_server.bat 会自动读取这些值，无需手动改脚本。
改完保存后重新双击 start_server.bat 即可生效。
注意：请保持 host 为 127.0.0.1（回环地址，任何电脑都指向本机自身），
切勿写成本机具体 IP（如 192.168.x.x），否则换到另一台电脑会因 IP 不同而无法访问。

────────────────────────────────────────
【目录结构（请勿随意删除）】
────────────────────────────────────────

customer_sku.json  SKU 数据
sku_images\      产品图片
config.json      配置（模板路径等）
templates\       网页界面
start_server.bat 启动脚本

────────────────────────────────────────
【数据备份】
────────────────────────────────────────
定期复制 customer_sku.json 与 sku_images\ 目录即可完整备份您的 SKU 数据。
