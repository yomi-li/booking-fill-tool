# 单证提取填充工具（本地网页应用 · 零 AI 规则引擎）

把装箱单 / 发票 / 报关单等多份 PDF、XLS 一键抽取字段，预览可编辑，导出填入固定模板
「客户货物运输托运书（系统下单用）」的 xlsx（**保留 LOGO**）。

抽取完全由 `rules.json` 驱动的可配置规则完成，**不依赖任何 AI 模型**：上传即转，
稳定、可复用、可自助维护。

## 启动
双击 `start.bat`（Windows）。自动开浏览器到 http://127.0.0.1:8000 。
若 managed venv 不可用，按提示自建 venv 并 `pip install -r requirements.txt`。

## 使用流程
1. **导入**：拖入或选择多份文档（装箱单、发票、报关单，PDF/XLS/XLSX 均可）。
2. **转换**：点「转换」→ 后端按 `rules.json` 规则抽取字段 → 网页预览。
   - 顶部「单票信息」仅供人工核对（模板只有货物明细列，无发货人/目的港/发票号对应列）。
   - 下方「货物明细」将写入模板，单元格可直接编辑，可增删行。
3. **导出**：点「导出已填文档」→ 浏览器下载填好的 xlsx（Excel COM 保留 LOGO）。
4. **规则编辑器**：切到「规则编辑器」页可查看/编辑/新建/删除抽取规则，并上传单份文档
   用某条规则做「测试预览」，确认能正确抽取后再用于正式转换。

## 规则引擎（零 AI）
`rules.json` 含 `settings`（币种别名、数字清洗）和 `rules`（每条规则对应一种文档版式）。
支持 4 种抽取模式：
- `table`：在网格里找表头行，按表头文本映射列（如 LGS、WNQ 箱单/发票）。
- `text`：对每行文本套正则捕获（如 KB 箱单/发票，PDF 表格塌缩成单列时用）。
- `text_block`：跨行块正则（报关单多行商品条目，如 KB 报关单）。
- `grid_relative`：Excel 报关单按单元格相对位置抓取（如 WNQ 报关单 XLS）。

合并逻辑：箱单+发票按「中文品名/英文品名/型号/总数量」合并；报关单再按总数量 1:1
补 HS 编码/品牌/中文品名，数量不匹配时按品名包含应用到全部对应行。

## 已内置版式（可直接用）
| 标识 | 文档 | 模式 | 来源 |
|---|---|---|---|
| 形式一 LGS | 装箱单+发票（XLS） | table | 发票自带 HS |
| 形式二 KB260991 | 装箱单+发票+报关单（PDF） | text / text_block | 报关单补 HS+品牌 |
| 形式三 WNQ | 装箱单+发票（PDF）+报关单（XLS） | table / grid_relative | 报关单补 HS |

## 注意事项
- 固定模板只有货物明细列，**单票级信息（目的港/发票号等）无处落位**，仅预览核对。
- 装箱单常给「该型号汇总」重量，工具自动换算为单箱口径填入。
- 导出优先用 Excel COM（Windows）保留 LOGO；非 Windows 退化为 openpyxl（会丢图）。
- 报关单数据（HS/品牌）依规则补入模板对应列；是否对外披露 HS 码请按贵司提单铁律决定。
- 新客户异常版式：在「规则编辑器」里照已有规则复制一份、改匹配条件与正则即可，无需改代码。
